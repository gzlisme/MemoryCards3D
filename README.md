# MemoryCards3D

一个用 **团结引擎（Tuanjie Engine）** 开发的 3D 双人记忆翻牌小游戏。  
从零开始，全程由 AI 辅助开发，本文档记录了它的诞生过程、踩过的坑和最终的成果。

---

## 🎮 这是什么游戏？

一张普通的课桌上，摆着 9 张圆形硬纸壳卡片，正面印着数字 1-9，背面统一是土褐色。  
游戏开始时，卡片背面朝上，随机打乱，摆成 3×3 方阵。

两名玩家轮流翻开卡片，必须严格按照 **1 → 2 → 3 → … → 9** 的顺序依次翻开。  
翻对了可以继续翻；翻错了，本轮翻开的卡片全部盖回，换对方继续。  
谁先按顺序翻完 1 到 9，谁就获胜。

这是一个考验记忆力和顺序推理的双人小游戏，适合孩子一起玩。

## 📋 原始需求（用户提出）

- 3D 游戏，固定俯视视角，不能旋转摄像机。
- 桌子是普通课桌，有厚度、木纹、光影。
- 卡片是圆形硬纸壳，有真实厚度，背面土褐色，侧面能看到纸板切边。
- 每张卡片在桌面上有清晰的实时投影。
- 翻牌动画约 0.3-0.5 秒，带缓动。
- 顶部 UI 显示：当前玩家、请找数字、连对计数。
- 胜利时弹出胜利画面和“再来一局”按钮。
- 不引入任何第三方插件或素材，所有资源代码生成。

## 🧭 开发历程（踩坑与里程碑）

### 1. 环境搭建
- 下载团结引擎 1.10.3，遇到许可证错误，通过 Tuanjie Hub 激活个人版解决。
- 创建 3D URP 项目 `MemoryCards3D`，路径 `D:\work\unity\MemoryCards3D`。

### 2. 场景基础（M1）
- 用 `SceneBuilder.cs` 程序化生成地板、课桌、正交俯视相机、方向光 + 实时软阴影。
- 程序化生成木纹贴图，磨砂木质材质。

### 3. 卡片系统（M2）
- **发现团结引擎内置圆柱只有 1 个子网格**，无法给顶/底/侧分别赋材质。
- 于是手搓三子网格圆柱体，用代码构造顶点、UV、三角形。
- 程序化生成 9 张数字贴图（七段数码管风格）和土褐色纸壳背面贴图。
- 制作 `Card.prefab`，实例化 9 张卡片，3×3 阵列。

### 4. 核心逻辑（M3）
- `Card.cs`：点击检测、协程翻牌动画（SmoothStep 缓动 + 抬升）。
- `GameManager.cs`：回合状态机、期待数字、翻错全盖回、换人、胜利判定。
- `UIManager.cs`：运行时创建 Canvas、三行信息、胜利面板、按钮。

### 5. 最大的坑：三角形绕向反了
- 现象：数字镜像、卡片正反面颠倒、部分卡片“隐形”。
- 排查：三次无头渲染探针 + 图像分析 + 网格数据转储。
- 根因：手搓网格时三角形顶点绕向与 Unity 正面判定相反（Unity 可见面 = 从观察方向看顶点逆时针排布）。
- 修复：交换每组三角形的第 2、3 顶点，让顶面朝上、底面朝下、侧面朝外。
- 顺带修正木纹拉伸轴，从“竖向沙丘纹”改为横向木纹。

### 6. 视觉调优
- 桌面颜色从原来的中棕色改为**胡桃木色**，让土褐色卡片更清晰。

### 7. 收尾问题（待修）
- **每次点 Play 卡片位置一样**：开局未洗牌，`ShuffleCardPositions()` 只在“再来一局”里调用。修复方案：在 `GameManager.Start()` 里加一次洗牌。
- **胜利后“再来一局”按钮无反应**：场景缺 `EventSystem`。修复方案：在 `UIManager.BuildUI()` 里防御性创建 EventSystem。

### 7. 收尾修复（已完成）

**问题一：每次点 Play 卡片位置一样**

- **现象**：停止 Play 再重新 Play，9 张卡片的位置和上一局完全一样。
- **根因**：洗牌只在 `SceneBuilder` 构建场景时随机了一次，结果被序列化进场景文件。每次 Play 加载的都是同一个固定布局。
- **修复**：
  - `GameManager.Start()` 里增加开局洗牌调用，每次游戏启动时重新随机。
  - `SceneBuilder` 删除构建期洗牌块，卡片按 1-9 顺序落格，随机性统一归运行时负责。
- **验证**：每次重新 Play，卡片位置都不同。

**问题二：胜利后「再来一局」按钮没反应**

- **现象**：玩到胜利后，点击「再来一局」按钮无响应。
- **根因**：场景里缺少 `EventSystem`。uGUI 的按钮点击依赖 EventSystem 分发事件，没有它，按钮永远收不到点击。卡片点击走的是物理射线（`OnMouseDown`），不需要 EventSystem，所以游戏能玩，唯独按钮失效。
- **修复**：`UIManager.BuildUI()` 里防御性创建 `EventSystem` + `StandaloneInputModule`（带 `using UnityEngine.EventSystems;`）。
- **验证**：胜利后点击按钮，卡片翻回背面、重新洗牌、UI 重置，可以接着玩。
